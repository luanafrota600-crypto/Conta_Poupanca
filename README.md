# Conta Poupança — Exemplo de Programação Orientada a Objetos

O projeto **Conta Poupança** é um exemplo acadêmico desenvolvido em Python para praticar os conceitos de Programação Orientada a Objetos (POO), simulando o funcionamento básico de uma conta bancária e de uma conta poupança com rendimento.

## 💻 Tecnologias

* Python 3

## ⚙️ Principais funcionalidades

* Criação de contas com titular, agência e número da conta;
* Depósito e saque com validação de valores;
* Transferência entre contas;
* Exibição das informações da conta;
* Conta poupança com taxa de rendimento (5%) aplicada ao saldo.

## 🧠 Conceitos de POO aplicados

* Classes e objetos;
* Construtores (`__init__`);
* Herança (`Poupanca` herda de `Conta`);
* Sobrescrita de métodos e uso do `super()`;
* Encapsulamento e validação de regras de negócio.

## 📁 Estrutura

```
Conta.py       Classe base (conta comum)
Poupanca.py    Classe filha (conta poupança com rendimento)
main.py        Exemplo de uso
```

## ▶️ Como executar

```
python main.py
```
